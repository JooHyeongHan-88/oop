# Python OOP 강의 슬라이드

`index.html` 하나로 된 HTML 슬라이드 강의 자료입니다. 브라우저로 열면 바로 발표할 수 있습니다.

## 조작법

| 키 | 동작 |
| --- | --- |
| `→` `Space` `PageDown` | 다음 슬라이드 |
| `←` `PageUp` | 이전 슬라이드 |
| `Home` / `End` | 처음 / 마지막 |
| `F` | 전체화면 |

- URL 해시(`#12`)로 특정 슬라이드를 바로 열 수 있습니다.
- 브라우저 인쇄(`Ctrl/Cmd + P`) → PDF로 저장하면 슬라이드 한 장이 한 페이지가 됩니다.

## 구성 (40장)

| 파트 | 내용 |
| --- | --- |
| 01 패러다임 | 절차 · 객체 · 함수형을 같은 ‘입금’ 예제로 비교 |
| 02 Class 기초 | class와 객체, 구성 요소, OOP 4대 특성, 예제에 쓰는 파이썬 도구(`@dataclass`, `@property`, `ABC`, `Protocol`) |
| 03 왜 OOP인가 | 절차 지향의 5가지 문제(흩어진 데이터, 무방비한 상태, if/elif 지옥, 복붙 중복, 교체·테스트 불가)를 한 장씩 코드로 비교 · AI Agent 코딩에서 OOP가 유리한 이유 |
| 04 SOLID | God 클래스(“class만 쓰면 끝일까?”) → 5원칙을 원칙마다 위반/준수 코드로 비교 → 요약표 |
| 05 정리 | 과설계 주의, 상속보다 조합 · 핵심 요약 |
| Appendix | Factory, Singleton, Adapter, Decorator, Strategy, Observer, Template Method |
